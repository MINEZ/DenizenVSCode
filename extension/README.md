DenizenScript VS Code Extension (MINEZ)
---------------------------------------

An extension to [VS Code](https://github.com/microsoft/vscode) to provide general language support for `.dsc` files written for [MINEZ/Denizen](https://github.com/MINEZ/Denizen), a fork of [Denizen](https://github.com/DenizenScript/Denizen) maintained for the MINEZ server.

This is an unofficial build and is not supported by the DenizenScript team. Please report problems to [our issue tracker](https://github.com/MINEZ/DenizenVSCode/issues), not to upstream.
